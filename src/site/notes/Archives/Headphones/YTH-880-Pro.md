# 為什麼會入手這支
經歷過「捏一下」買各種東西因而連續好幾個月都吃土的感覺，希望自己這次能以完全沒有負擔的預算購入一支能舒服聽的耳罩
其實原本的主力機ikko oh1s配上AEX70耳塞配戴上已經很舒服，但連續聽久了還是有點負擔(沒有想要休息一下的意思XD)
再加上上一次入手耳罩是在博客來隨便買的650元耳罩，它漏音嚴重，又很刺，平常無法好好用來聽音樂~~也沒辦法聽一些色色的東西~~
所以就將預算訂在2000元左右
而到處爬文後才注意到原來台灣有一個經營很久的牌子，在海鮮店上和他們聊了一下，覺得他們人不錯，好印象++
再加上880系列某摸摸上折完價格落在2100，還滿剛好的
就入手封閉式的880 pro了
(順帶一提，晚上7點下單隔天14點就收到了，急性子人大喜)

# 聽起來的感覺
## 入耳配置(原先的配置)
耳機：ikko oh1s + AEX70耳塞
線：Effect Audio Ares S 4.4平衡
訊源：Fiio M15S + Amazon Music JP
用低增益即可良好驅動

## 耳罩配置
耳機：YTH-880 Pro
線：Effect Audio Ares S 4.4平衡 + 澤豐mmcx轉3.5轉接頭
訊源：Fiio M15S + Amazon Music JP
用低增益即可達到平時聽的音量，但不確定是否為心理作用，覺得用超級大耳模式音場比較大，所以後來都是用超級大耳模式

## 主觀感覺
假設在入耳上
- A曲子非常好聽，好聽到我會沈醉於每一分每一秒
- B曲子不錯聽，順順聽過去
- C曲子會跳過

那到了耳罩上
- A曲子會跳過
- B曲子不錯聽，順順聽過去
- C曲子非常好聽，好聽到我會沈醉於每一分每一秒

就是反過來的感覺XDDDDD也是前面「in some sense互補」的意思
補充說明跳過不是覺得不好聽，而是會想先聽另外兩個分級的曲子所以先跳過了

對我來說換耳罩最大的收獲是，相較於入耳，更能感受到音樂包住自己的感覺
以及樂器的形體從像是一個點，變成一個音箱(?)的感覺，更加立體
這種感覺在弦樂器(鋼琴、提琴等)以及鼓上更為明顯，尤其是氣勢滂薄的鼓聲到了耳罩上就是一個字「爽！」
不過也可能是我本來就比較注意這幾種樂器才會感受比較大
另外在耳罩上更能夠聽出來聲音的遠近、位置
入耳上也聽得到，只是耳罩將位置拉得更開，在觀察樂器或人聲的位置時花的力氣更少

然而，由於很多東西都變「大片」，在某些聽起來要是一點一點的聲音上會有點散掉，導致失去了能在入耳上聽到的精緻感
另外相對於入耳，耳罩的人聲遠了一些，在一些曲子上會有樂器搶走主唱位子、喧賓奪主之感
雖然我平常就關注樂器聲比較多，所以不會覺得問題很大(甚至還有點開心XD)
但喜歡聽人聲的朋友這點可能要注意一下
另外個人覺得金屬樂的表現和入耳比起來有點差強人意，不過暫時沒辦法描述覺得是哪邊出了問題

額外的收獲是，耳罩聽asmr的效果出奇地好！
一些耳語真的很像是在「耳朵旁邊」說的，而不是在「耳朵裡面(入耳的感覺)」說的
耳朵按摩也像是真的按在耳朵上
![周防](https://i.imgur.com/BTDbhoE.jpeg)

目前還沒拿去聽真的很色的東西，所以這方面沒辦法評論(???)，唯一可以說的是在一般音量下完全不用擔心別人聽到XD

原線是3.5(6.3)，上了平衡後差異巨大，個人強烈認為一定要上平衡
但為了2000元的耳機特地去買平衡線好像就失去了高cp值的爽感
所以會覺得手邊有平衡線的再考慮
另外由於以前聽過開放式的耳罩，相較起來會覺得封閉式的有點悶
和880 pro同一系列的還有開放式的880 classic，在意悶的可能classic會更適合
但就不太確定classic漏音的程度了

# 結論
竊以為可能適合的朋友有：
- 預算低至2000元而且不想捏一把
- 手邊剛好有平衡線
- 適應封閉式
- 喜歡聽樂器遠勝於人聲
- 在意保固(台灣公司，要是真有什麼三長兩短維修方便，保固一年。而且原廠配件如耳罩等便宜好取得)

像個人就覺得2000元價位有這個聲音真的 滿爽的XDD
